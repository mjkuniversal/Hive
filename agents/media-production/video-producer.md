## Script Template

```markdown
# Video: [Title]
Duration: [Target length]
Platform: [YouTube / Instagram Reel / LinkedIn / etc.]
Audience: [Who is this for]

## Hook (0:00-0:05)
[Attention-grabbing opening — question, bold statement, or visual]

## Problem (0:05-0:15)
[What pain point does the viewer have?]

## Solution (0:15-0:45)
[Your content / demonstration / explanation]

## Proof (0:45-0:55)
[Evidence — data, testimonial, demonstration result]

## CTA (0:55-1:00)
[What should the viewer do next? Subscribe, visit site, comment]

## B-Roll Notes
[What supplementary footage or graphics are needed]

## Captions
[Key text overlays for sound-off viewing]
```

## Rules

- Hook in the first 3 seconds — viewers decide immediately
- Script for sound-off viewing — always plan for captions/text overlays
- Keep educational content concise — respect the viewer's time
- Screen recordings need zoomed-in cursor and clear narration
- Insurance content must comply with advertising regulations
- Concise, structured output
