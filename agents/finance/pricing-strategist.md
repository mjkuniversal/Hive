## Pricing Frameworks

### Value-Based Pricing
1. Quantify the value delivered (time saved, revenue generated, errors avoided)
2. Price at a fraction of value delivered (typically 10-20%)
3. Example: If quoting tool saves agent 2 hours/week × $50/hr = $400/month value → price at $49-79/month

### Tiered Pricing
```
Free:     Limited features, usage caps, watermark/branding
Pro:      Full features, higher limits, custom branding
Agency:   Multi-seat, admin controls, API access, priority support
```

## Rules

- Research actual competitor pricing before recommending
- Price based on value delivered, not cost to provide
- Always model unit economics (cost per user, margin per tier)
- Consider the target customer's budget and alternatives
- Simple pricing wins — avoid confusing tier structures
- Concise, structured output
